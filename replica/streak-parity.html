What the audit found

  • One pipeline only. The database has no pipelines table, so stages are global. You run 166 Streak pipelines, mostly one "<Client> - LG" pipeline per client. This is the biggest gap.
  • Fields are hard-coded. Interest, Fit, Category, Next Steps, Done and Thread are fixed columns copied from the MAbSilico template. Streak lets each pipeline define its own columns.
  • No login. The login libraries are installed but never wired. The role switch is never shown, so New Deal, Edit, Delete, Settings and Admin are hidden on every load.
  • Data is wiped on every restart. The server reloads an April 2025 MAbSilico CSV each time it boots.
  • Several screens are mock or unreachable. Emails, saved views and custom fields use fake data; Tasks has a page but no menu link; drag-and-drop kanban is not connected.
  • Deploy blocker in the code. The database driver is Replit's Neon driver, which won't talk to the plain Postgres the VPS runbook installs.
  • What works: contacts list and editing, moving a deal between stages, the activity timeline, and dashboards built on real numbers.

Recommended build plan

  1. Rebuild the data model first. Pipelines, per-pipeline stages and field definitions, organizations, several contacts per box, real users and login. Patching the current single-pipeline schema would cost more than replacing it; the screens can mostly be kept.
  2. Spreadsheet grid with saved views. Inline editing, sort, filter, group by any column, saved views. Your Urban Factory pipeline alone has six saved views (By Month, By Week, By Leader, By Interest, By Fit).
  3. Import straight from Streak. Your Streak account is connected, so the 166 pipelines, their stages, fields and boxes can be copied in directly. This replaces the boot-time CSV wipe and is the real test of readiness.
  4. Box essentials. Comments, tasks with assignee and due date, call logs, meeting notes, files, CSV export, global search.
  5. Then the extras. Webhooks and API, automations, Form.gershonCRM.com feeding boxes, and an AI box summary through the planned Intelligence menu.
  6. Look and feel. Built in the shared Gershon design (Linalysis layout, Gershon.ai red), not Streak's look.

Left out on purpose

Streak's Gmail features: working inside Gmail, automatic email sharing, open and click tracking, snippets, thread splitter, and mail merge. Mail merge outreach already runs through Snov.io and Straight-in; that call stays with you (roadmap Epic 6).
